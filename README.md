# Scratch

Personal learning repository for Rust and development tools.

## Contents

### Rust
Learning Rust through [The Rust Book](https://doc.rust-lang.org/book/) with practical exercises building toward a touchscreen GUI application.

**[View Learning Plan](rust/rusty_contemplations.md)**

### Helix
Configuration files for the [Helix](https://helix-editor.com/) editor written in Rust with extensions available for all your favourite programming languages. The configuration file here includes rust-analyzer which helps you a lot on the initial hurdles you face when starting with Rust. Highly recommended! :crab:
